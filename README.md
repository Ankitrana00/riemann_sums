# Riemann Sums converging to Integrals Simulation

An interactive, animated micro-simulation that explains Riemann Sums converging to integrals (Class 11th & 12th curriculum). Designed with premium aesthetics, glassmorphism UI, and real-time visualization of approximation error.

## Features
- **Visual "Aha!" Moment:** Real-time red-highlighted error area showing the difference between the approximation rectangles and the actual curve. As $N \to \infty$, the error visualizes shrinking to $0$.
- **Approximation Methods:** Supports Left, Right, and Midpoint Riemann sums.
- **Dynamic Parameters:** Instantly adjustable number of rectangles ($N$) from 1 to 150.
- **Synchronized Representation:** Real-time calculation readout of the Estimated Area, Exact Integral Area, and Absolute Error.
- **Premium Aesthetics:** Sleek dark-mode interface with responsive canvas rendering.
